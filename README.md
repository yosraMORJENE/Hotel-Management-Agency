# 🏢 Hotel Reservation Agency System – Symfony 6

This project is a **Symfony 6 web application** developed for a **hotel reservation agency**.
The agency manages **partner hotels**, their capacities and prices, and handles **client reservations**.

This application was created as part of a **university assignment**, respecting all required technical and functional constraints.

---

## 🎯 Project Purpose

The goal of this project is to build a web platform that allows an **agency** to:
- Manage hotels it collaborates with
- Register clients and their reservations
- Organize hotel capacities and pricing
- Provide a clean and reusable web interface

---

## 🛠️ Technologies Used

- PHP 8+
- Symfony 6.*
- Doctrine ORM
- Twig Template Engine
- MySQL
- Bootstrap 5
- Symfony CLI
